PAC-WOMEN
=========

CONTROLS
--------
Arrow Keys | WASD | HJKL    Move Pac-Man
P			                Pause / Resume

OPTIONS
-------
The game uses the default settings from config.json.

CONFIGURATION
-------------
The game includes a default configuration.

To use a custom configuration file:

    ./pac-man my-config.json

If no configuration file is provided, the bundled
config.json is used automatically.

OBJECTIVE
---------
Eat all the pellets and avoid the ghosts.

GAME OVER
---------
You lose a life when a ghost catches you.
The game ends when all lives are lost.
